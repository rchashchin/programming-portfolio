# Python Practice

Small programs written while learning Python (2023): contest-style problems, a Sudoku solver, classes and inheritance, and geometry with the `math` module.

| File | What it covers |
|---|---|
| `shapes.py` | Classes for geometric shapes (triangle angles and area via the law of cosines) |
| `music.py` | Classes and inheritance (bells, cars) |
| `sudoku.py`, `sudoku3x3.py`, `sudo.py` | Sudoku logic and solving with constraint sets |
| `contest_1.py`, `contest_3.py`, `contest_4.py` | Contest-style problems (string and grid manipulation) |
| `set.py` | Experiments with Python sets |
| `p1.py`, `numbers_2.py`, `sudoku_main.py` | Early exercises |

Note: `sudoku3x3.py` uses `time.clock`, which was removed in Python 3.8. Replace it with `time.perf_counter` to run it on a modern version.
